## 三、把巴夏的科技主张分成三层

读这批材料时，**必须把三类东西分开**，否则容易把叙事当技术、把技术当事实：

| 层 | 内容 | 例子 | 处理方式 |
|------|------|------|------|
| **第一层：可检验的物理陈述** | 有明确对象、有测量方式、有成功判据 | 金属球两端频率有差、施加 B 后球滚向 B | 可以设计实验；**必须设零假设** |
| **第二层：机制解释** | 对现象的解释性主张 | 位置是物体的属性；隔离场重新定义时空坐标 | 只能作为假说；**不得作为工程输入** |
| **第三层：宇宙论与叙事** | 无法在当前技术下触及的主张 | 3000 年科技差距；混血种族；月球基地 | 归档、不评价、**绝不进入验收标准** |

> **三层混用的后果**：可行性报告此前把「25.4mm」当工艺自定值，正是因为没有先分清「巴夏给了什么」（第一层）与「我们自己补什么」。详见 `../勘误与修订_巴夏铜球原始尺寸原话与首球选型表.md`。

## 四、这批内容的共同骨架

巴夏所有科技主张，背后其实是**同一套三条公理**的展开：

1. **万物是频率**——物质是「原初能量」的特定振动变体（`every physiological object is a specific vibration of the primal energy`）
2. **位置是物体的属性**——不是物体所处之处，而是物体自身可变的变量之一
3. **意识是第一性**——飞船有知觉，驾驶靠意识连接，技术是意识与物质的结合

从这三条出发：

```
公理1+2 → 金属球位置频率实验（桌面可做）
        → 瞬移／位置变量（飞船级）
        → 时空天线（把「以太场」当能量源接收）
公理3   → 飞船意识驾驶 / AI 路径 / 通灵即生物接收器
公理1   → 振动疗愈 / 声波悬浮 / 零点能提取
```

**这就是为什么「金属球实验」在整个体系里位置特殊**：它是巴夏给的**唯一一个可以在桌面尺度上、用现有仪器做的**可证伪实验。其余主张都要求「3000 年后的技术」。

## 五、诚实边界

1. **视频语录为自动字幕转写**，存在同音误识（如 `their`/`there`、专名拼写）。引用前请回看原视频核对。人工字幕（部分视频有 zh-Hans）质量更好。
2. **本系列只做归档与结构化，不做真伪判定。** 涉及可检验的部分（金属球实验）已在可行性报告中单独立项。
3. **付费墙内容未获取**：BasharTV 的 45 部传讯均为付费视频，本系列只归档**目录**，不含正文。
4. **中文译名不统一**：Essassani 有「艾莎莎尼/爱莎莎尼」两种写法；Yahyel 有「雅耶奥/雅耶」；本系列统一用「艾莎莎尼」「雅耶奥」。
5. **巴夏本人不承认自己是名字**，Bashar 在阿拉伯语中意为「信使」，是借用称呼。
