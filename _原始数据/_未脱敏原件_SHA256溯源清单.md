# `_未脱敏_勿公开/` 原件 · SHA-256 溯源清单

> **原件不入库，但「有没有被改动过」依然可查。** 本清单是那些原件的公开替代凭证：
> 任何人拿到本地原件，按 `SHA-256` 一比即可确认是否与归档当日逐字节一致，
> 而无需公开原件内嵌的鉴权参数。

## 为什么原件不入库

`_原始数据/` 的三个原始抓取件内嵌**元宝预签名下载 URL**（腾讯云 AccessKeyId + `q-signature`）。实测：

| 项 | 实测值 |
|------|------|
| 需脱敏参数 | 5 类（`q-ak` / `q-signature` / `sign` / `signature` / `token`） |
| 出现次数 | 542 处（已全部替换为 `REDACTED` 的版本**已入库**） |
| 唯一 AccessKeyId | 3 个（36 位 `AKID…`） |
| 签名有效期 | 40 处 1 年（至 2027-09-20）；**200 处 10 年（至 2036-09-17）** |
| 被签对象 | 15 个，均在 `userassets.yuanbao.tencent.com/artifacts/1345/…` 下 |
| SecretKey 是否泄露 | **否**（无 `q-key=` 独立参数，无 SecretKey 字段） |

结论：**密钥未泄露，无法用它伪造新签名**；但 240 处签名是**针对上述 15 个对象的长期取件凭证**，
公开等于替第三方（元宝 / 腾讯）的存储桶开一个不记名窗口，故原件仅本地留存。

## 验证方法

```bash
# Windows
certutil -hashfile "_未脱敏_勿公开\_原始数据\chat.json" SHA256

# Python（跨平台，逐个核对）
python -c "import hashlib,glob,os;[print(hashlib.sha256(open(p,'rb').read()).hexdigest(),' ',p) for p in glob.glob('**/*',recursive=True) if os.path.isfile(p)]"
```
