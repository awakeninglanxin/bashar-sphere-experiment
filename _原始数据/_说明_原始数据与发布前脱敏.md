## 二、发布前脱敏记录（2026-09-21）

### 为什么脱敏

元宝分享页的原始抓取里，内嵌了**预签名下载 URL**，形如：

```
.../文件名.md?q-sign-algorithm=sha1&q-ak=AKID…&q-sign-time=1789875925;2105235925&q-signature=…
```

- `q-ak` 是**腾讯云 AccessKeyId**
- `q-signature` 是该 URL 的**签名**，且 `q-sign-time` 显示其**有效期直到 2036 年**

也就是说，把这些 URL 公开，等于公开一批**长期有效的下载凭证**。
这类参数没有任何档案价值（纯鉴权材料），因此公开前一律清除。

### 清了哪些

| 参数 | 归属 | 处数 |
|------|------|------|
| `q-ak=AKID…` | 腾讯云 AccessKeyId | 248 |
| `q-signature=…` | 预签名 URL 签名（有效期至 2036） | 248 |
| `sign=…` | 微信图片 CDN 签名 | 8 |
| `signature=…` | 公众号文章分享链接签名 | 32 |
| `token=…` | 视频号预览 token | 6 |

**合计 542 处**，跨 5 个文件。

### 怎么清的

- **只替换参数的值**为 `REDACTED`，**URL 的路径与文件名一律保留**，provenance 不丢
- 同一份文件里存在 4 种编码形态（明文 `&`、HTML 转义 `&amp;`、JSON 转义 `\u0026`、
  URL 编码 `%26…%3D`），脚本按**值特征**匹配，逐一覆盖
- 保留的非敏感参数：`q-sign-algorithm`、`q-sign-time`、`q-key-time`、
  `q-header-list`、`q-url-param-list`、`resourceId`、`appid`

### 校验结果

| 项 | 结果 |
|------|------|
| 残留 `AKID` | 0 |
| 残留 `q-signature` 值 | 0 |
| 两份 JSON 语法解析 | 通过 |
| 除目标参数外内容变动 | 无 |

### 未脱敏原件在哪

字节未改动的原件留在 `_原始数据/_未脱敏_勿公开/`（保持原目录层级）。
该目录**已写入 `.gitignore`，不在公开仓库内**，仅供本地留存。

> ⚠️ 若日后重新同步本归档，注意**不要**把这个目录带进公开仓库。
