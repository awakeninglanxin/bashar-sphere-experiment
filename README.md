### 这个网页讲什么（不超过 500 字）

**这是什么。** 巴夏（Bashar）在 1998 与 2017 两次传讯里提到：一只空心导电球在桌上静息，**换一个位置，就换一个频率**——他把这叫物体「本有的空间地点频率」。这句话从未被做过实验。本页做的第一件事，就是把它压缩成**一张桌子、一只球、三十分钟基线**就能验的四道判据：规格达标 → 基线可复现 → 主动响应 → 外部复现。

**全页十四章，分三层，末章为挑战清单。** ① **可验层**：把原话拆成 15 条硬要求，定出首球规格 Ø80×0.8、八点传感阵列、开环扫描协议、误差预算（谁在伪装成「位置签名」）。② **方法论层**：与 Allais 视差摆、NIST／JILA 引力红移实验逐条对照——相同与不同、可继承清单、控制变量七机制，以及从同高度到正交对比的变量矩阵。③ **远景层**：从「读一个点」推到五级台阶，落到全球运动场扫描的七类三十余项功能，最后算一笔经济账——同频冷焊、食物直达、无创手术、瞬移物流、城市级瞬移各会重定价哪些科目。

**三层严格分离**：原话、我们的补充、远景推演全程分开标注；远景**不进入任何验收标准**，市场数字只作量级参照。右上角可切换白天／暗黑。

**结论只有一句。** 它值多少钱不是重点；重点是——即使效应被否定，**最大的下行损失也只是那张桌子和那只球**。

## 十、三层分类法（读这批材料的前提）

巴夏的科技主张必须分成三层，**混用会把叙事当技术、把技术当事实**：

| 层 | 内容 | 例子 | 处理 |
|------|------|------|------|
| **第一层：可检验的物理陈述** | 有对象、有测量方式、有判据 | 金属球两端频率有差；施加 B 后球滚向 B | 可设计实验；**必须设零假设** |
| **第二层：机制解释** | 对现象的解释性主张 | 位置是物体的属性；隔离场 | 只作假说；**不得作为工程输入** |
| **第三层：宇宙论与叙事** | 当前技术无法触及 | 3000 年差距；混血种族；月球基地 | 归档、不评价；**绝不进入验收标准** |

**整个归档里，只有「金属球位置频率实验」一条落在第一层。** 其余都在第二、三层。
